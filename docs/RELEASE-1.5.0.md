# DropLink 1.5.0 — 个人版 / 安全版

> 这是本仓库第一个「一分二」的版本：同一份代码出两个产物，按使用场景选。

## 下载哪个

| 文件 | 说明 |
|---|---|
| `DropLink.exe` | **个人版**：家里 / 自己设备之间，快速直传（HTTP，明文，无审批） |
| `DropLink-Secure.exe` | **安全版**：办公室 / 公共 Wi-Fi，TLS 加密 + 设备审批 + 传输前确认 |
| `DropLink-Android.apk` | 安卓端 1.4.8（电脑 → 手机方向接收用） |
| `SHA256SUMS.txt` | 校验和，`certutil -hashfile <文件> SHA256` 对照 |

**两个版本互不兼容**：两端要装同一族，同一台电脑上别同时开。

## 安全版新增了什么

- **TLS 全链路加密**：首次启动自签 ECDSA P-256 证书，拿不到证书就拒绝启动，不回落明文（窗口里显示 8 位指纹供核对）。
- **设备信任**：新设备第一次连必须在本机点「接受」，之后可撤销；撤销后立刻 401。
- **传输前确认**：对方先只发文件清单（名字/大小/来源），本机点接受才收字节；未接受时一个字节都不落盘。
- **逐文件一次性 token**：绑定会话+文件，重放/跨文件/过期一律 403。
- **统一错误码**：401/403/409/410/422/429/507 + 机器可读 `code`（仅安全版）。
- **写入侧路径加固**：路径穿越、UNC、NTFS 数据流、软链/目录联接、Windows 保留名、超深目录，一律拒。
- **分接口限流**：list 50/s、preview 30/s、upload 20/s（令牌桶，本机豁免），同会话并发 ≤2。
- **日志脱敏**：路径只留文件名+哈希前缀、局域网 IP 打码、PIN/token 打码、事件带时间。
- **配额与残留清理**：可配配额（超限 507）、24 小时 `.part` 清理（只删本程序生成的）。
- **Web 面**：Cookie `Secure`、Origin/Sec-Fetch 校验、Host 白名单（421）、XFO/CSP/nosniff，可执行内容（html/svg 等 9 类）强制下载。

## 个人版

行为与 1.4.x 一致：6 位配对码、直接上传、不弹确认。

## 安卓端 1.4.8

- 修复**搜索永远为空**：服务端把结果放在 `results`，前端读的是 `entries`，字段名对齐后恢复；顺带补了中文输入法组词（compositionend）与回车直搜。

## 已知限制（请先看）

- **没有代码签名**：Windows SmartScreen 首次运行会提示「未知发布者」。请用 `SHA256SUMS.txt` 核对，或自行从源码构建。
- **安全版自签证书**：浏览器首次打开必有「证书不受信任」提示，属正常；请核对窗口里的 8 位指纹后再继续。
- **不防端点被控**：电脑或手机上有木马时，文件在落盘前就能被读走，任何传输工具都挡不住。
- **两版不互通**：安全版要求 TLS，个人版客户端连不上是预期行为。

安全模型与「明确不防什么」详见仓库根目录 `SECURITY.md`。

## 校验

```
certutil -hashfile DropLink.exe SHA256
certutil -hashfile DropLink-Secure.exe SHA256
```

与 `SHA256SUMS.txt` 中的值逐位比对。
