# DropLink 互传

电脑 ⇄ 手机，同一个 Wi-Fi 内直接互传文件。**不经过互联网、不上传云端、不消耗手机流量。**

> **双击 `DropLink.exe` 就能用** —— 这是一个独立的单文件程序（13 MB），
> **不需要装 Python**，也不需要联网。会弹出程序窗口，显示二维码和配对码。

手机端不用装 App —— 用浏览器打开电脑给的地址就能用，还能「添加到主屏幕」当 App 用。

---

## 一、为什么说不消耗流量

传输走的是**局域网**（家里路由器 / 电脑热点），数据只在两台设备之间流动：

```
手机  ──Wi-Fi 局域网──  电脑（DropLink 服务）
        ↑ 不经过运营商基站，不出门
```

- 没有 Wi-Fi？让电脑开启 **移动热点**，手机连电脑的热点，同样不走流量。
- 反过来也可以：手机开热点，电脑连手机热点（电脑侧的网络地址会变，窗口里会重新显示）。
- 传输速度取决于路由器，一般 **10–60 MB/s**，比网盘快得多。

## 二、开始使用

1. 双击 **`DropLink.exe`**，会弹出程序窗口：

   - 中间一个大**二维码**，手机直接扫就能打开；
   - 下面一行是**手机访问地址**（也可以手动输入）；
   - 再下面是 **6 位配对码**，手机第一次打开时要输；
   - 底部三个按钮：打开电脑界面 / 打开接收文件夹 / 停止服务并退出。

2. 电脑端的**文件管理界面**会自动打开（Edge 或 Chrome 的独立窗口，没有浏览器标签栏）。
3. 手机连**同一个 Wi-Fi**，扫二维码或打开那个地址，输入配对码即可。
4. 关掉这个窗口（或点「停止服务并退出」）就停止服务，任何设备都连不上。
   点窗口的「最小化」会缩到**右下角托盘**，双击托盘图标可以叫回来。

> 首次启动时 Windows 可能弹出「防火墙」提示，勾选**专用网络**并允许即可。
> 如果手机打不开，见下面「常见问题」。

### 它会在电脑上留下什么

- 第一次运行时，会把内置的 Python 运行时释放到
  `%LOCALAPPDATA%\DropLink\runtime`（约 13 MB，之后直接复用，不会重复释放）。
- 手机传来的文件默认保存在 **桌面\DropLink 接收**（可在界面「我的」里改）。
- 运行日志在 `%LOCALAPPDATA%\DropLink\droplink.log`。
- 卸载：删掉 `DropLink.exe` 和上面那个 `DropLink` 文件夹即可，不写注册表。

## 三、能做什么

| 功能 | 说明 |
| --- | --- |
| 浏览电脑文件 | 手机端可进入桌面、下载、文档、图片、视频、音乐以及各个磁盘 |
| 在线预览 | 图片、视频、音频、PDF、文本直接在手机上看，不用先下载 |
| 下载到手机 | 点文件 →「下载」，保存到手机本地 |
| 手机传电脑 | 「传文件」里选文件 / 照片 / 视频 / 拍照 / 整个文件夹，实时进度条 |
| 电脑传手机 | 电脑上点文件的「分享」，生成二维码，手机扫一下直接下载（24 小时有效） |
| 剪贴板 | 两端互发文字、链接，复制粘贴不用打字 |
| 批量操作 | 长按或点「选择」多选，可打包成 zip 一次下载 |
| 接收目录 | 手机传来的文件默认在桌面的 **DropLink 接收** 文件夹，可在「我的」里改 |
| 回收站删除 | 在手机上删除电脑文件会进**回收站**，可还原，不会直接消失 |
| 传输中心 | 传文件时实时显示速度曲线、数据流动画、进度环，跑完有完成动效 |
| 深浅主题 | 右上角按钮切换浅色 / 深色，默认跟随系统 |
| 独立窗口 | 电脑端用 Edge / Chrome 的「应用模式」打开，像原生 App 而非浏览器标签 |

## 四、常见问题

**手机打不开地址 / 一直转圈**

1. 确认手机和电脑连的是**同一个** Wi-Fi（不要一个连 5G、一个连访客网络）。
2. 电脑上先试 `http://127.0.0.1:8848` 能不能打开。能开说明服务正常，问题在网络。
3. 关闭电脑上的 VPN / 代理软件（它们会改路由）。
4. 让 Windows 防火墙放行：右键 **`放行防火墙.bat`** →「以管理员身份运行」。
5. 公司/学校 Wi-Fi 常开启「AP 隔离」，设备之间不能互访 —— 改用电脑或手机开热点。

### 关于防火墙（有防火墙的电脑必读）

DropLink 要收手机连进来的请求，Windows 防火墙默认会拦掉这类「入站连接」。
**不用关闭防火墙**，只要放行一个端口或程序即可：

**方式一（推荐，最简单）**：右键 `放行防火墙.bat` →「以管理员身份运行」。
它会放行 TCP 8848–8867 端口 + 程序 `pythonw.exe`，并同时覆盖「专用」和「公用」网络。

**方式二（手动，图形界面）**：

1. 开始菜单搜「**Windows 安全中心**」→「防火墙和网络保护」→「高级设置」。
2. 左侧点「**入站规则**」→ 右侧「**新建规则**」。
3. 类型选「**端口**」→ 下一步。
4. 选「**TCP**」和「**特定本地端口**」，填 `8848` → 下一步。
5. 选「**允许连接**」→ 下一步。
6. 三个勾（域 / 专用 / 公用）**全部勾上** → 下一步 → 起个名字 → 完成。

**为什么你之前连不上（最常见的原因）**：Windows 把家里的 Wi-Fi 标记成了
「**公用网络**」，而放行规则只勾了「专用」——规则就对不上号，等于没放行。
所以上面每一步都强调「**公用**」也要勾。也可以在
「设置 → 网络和 Internet → Wi-Fi → 当前网络属性」里把网络改成「**专用网络**」。

> 提示：放行脚本只对默认端口（8848）及顺延端口（8848–8867）生效。
> 如果手机还是连不上，优先检查是不是连错了 Wi-Fi，或路由器开了 AP 隔离。

**配对码在哪看**

启动窗口里，或电脑界面「我的 → 配对码」。每次重启服务都会换一个新的；已配对过的手机 30 天内不用再输。

**想换个端口**

`启动.bat` 里改不了，直接用命令行：`python server.py --port 9000`。

**能传多大的文件**

没有单文件大小限制（受磁盘空间限制），上传中断会留下 `.part` 临时文件，可手动删除。

**安全吗**

- 只有同一局域网内的设备能访问；
- 首次连接必须输入 6 位配对码，连续输错 5 次锁定 1 分钟；
- 手机只能**上传**到接收目录，不能在电脑任意位置写入；
- 删除操作一律进回收站；
- 关掉启动窗口，服务立刻停止，任何设备都连不上。

**需要联网吗**

运行和传输都不需要。只有「安装增强组件.bat」那一步需要联网下载两个小库。

## 五、二维码是内置的，不用装任何东西

程序自带了一个**零依赖的二维码生成器**（`qrmini.py`：手写 QR 编码 + Reed-Solomon 纠错 + PNG 输出），所以：

- 启动窗口里直接印出可扫的**字符画二维码**；
- 「我的 → 手机连接方式」里有二维码图片，手机扫一下就打开；
- 电脑上分享文件生成的也是二维码，手机扫码直接下载。

**完全离线可用**，不需要 `pip install` 任何东西。

---

## 六、可选：图片缩略图

唯一的可选项是 `Pillow`：装上之后，手机浏览电脑图片时会显示**真实缩略图**，而不是统一图标。

双击 **`安装增强组件.bat`**（会把 `pillow` 装到本目录的 `vendor/` 里，不污染系统 Python）。装不上也完全不影响使用。

## 七、文件说明

```
DropLink 互传/
├─ DropLink.exe        ← 双击这个开始用（独立单文件，内含运行时）
└─ 放行防火墙.bat      ← 手机连不上时，右键以管理员身份运行

开发源码（droplink/，可选，改代码才需要）：
├─ app_main.py         ← EXE 入口：起服务 + 弹原生窗口
├─ gui.py              ← 原生窗口（纯 ctypes 调 Win32，不用 tkinter）
├─ server.py           ← 服务端（纯 Python 标准库）
├─ qrmini.py           ← 零依赖二维码生成器（QR 编码 + PNG）
├─ web/                ← 网页界面（HTML/CSS/JS，无外部依赖）
├─ build/launcher.cpp  ← 自解压启动器（C++，把运行时从 EXE 尾部释放出来）
├─ build/build_exe.py  ← 打包脚本（裁剪标准库 → 打 zip → 编启动器 → 拼 EXE）
├─ 启动.bat            ← 用已装的 Python 直接跑源码
├─ 安装增强组件.bat    ← 可选：图片缩略图（Pillow）
└─ config.json         ← 接收目录等设置（自动生成）
```

命令行参数（用 `启动.bat` 或直接跑源码时可用）：

```
python app_main.py [--port 8848] [--pin 123456] [--recv "D:\共享"] [--no-gui] [--no-browser]
```

重新打包 EXE：

```
python build/build_exe.py -o "C:\path\to\DropLink.exe"
```
